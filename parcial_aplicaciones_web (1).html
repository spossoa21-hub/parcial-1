1Arquitectura Web — modelo cliente‑servidor25 pts

El navegador arma la solicitud HTTP/HTTPS a partir de la acción del usuario; el servidor la procesa y devuelve una respuesta (HTML/CSS/JS o datos); el navegador la interpreta y renderiza la página final para el usuario.

2HTML5 — estructura semántica20 pts

Jerarquía: <html> contiene a <header>, <nav>, <main> y <footer> como hijos directos; <main> a su vez contiene <section> y, dentro de ella, <article> para agrupar contenido independiente y reutilizable.

3CSS3 — Flexbox vs. Grid20 pts

CaracterísticaFlexboxGrid
Dirección del layoutUna dimensión (fila o columna)Dos dimensiones (filas y columnas a la vez)
Tipo de diseñoDistribución lineal y flexible de elementosDistribución en cuadrícula, con celdas y áreas definidas
Uso principalBarras de navegación, alinear elementos, distribuir espacio dentro de un contenedorLayouts completos de página: encabezado, sidebar, contenido, pie
Ejemplo de aplicacióndisplay:flex; justify-content:space-between;display:grid; grid-template-columns:1fr 3fr;

4Box Model de CSS15 pts

Content: área donde vive el texto/imagen. Padding: espacio interno entre el contenido y el borde. Border: línea que envuelve el padding y el contenido. Margin: espacio externo que separa la caja de otros elementos.
